## Spacing Scale

Based on 8-point grid. All values are multiples of 0.8rem (8px).

| Token | CSS Custom Property | rem value | px equivalent | Usage |
|-------|--------------------|-----------|--------------:|-------|
| xs | `--space-xs` | 0.4rem | 4px | Icon gaps, tight inline padding |
| sm | `--space-sm` | 0.8rem | 8px | Compact element spacing, small gaps |
| md | `--space-md` | 1.6rem | 16px | Default element spacing, button padding |
| lg | `--space-lg` | 2.4rem | 24px | Section inner padding, card body padding |
| xl | `--space-xl` | 3.2rem | 32px | Layout gaps between components |
| 2xl | `--space-2xl` | 4.8rem | 48px | Major section breaks |
| 3xl | `--space-3xl` | 6.4rem | 64px | Page-level vertical rhythm |
| 4xl | `--space-4xl` | 12.8rem | 128px | Hero and full-bleed section padding |

Exceptions:
- Touch targets: minimum 4.4rem (44px) height on all interactive elements — not from scale, per WCAG 2.5.5
- BrandSlider existing vars (`--gap`, `--logoH`, `--duration`) are preserved as-is — do not replace with spacing tokens

## Typography

**Base:** `html { font-size: 62.5% }` → 1rem = 10px.

### Font Families

| Token | CSS Custom Property | Value |
|-------|--------------------|-----------------------------------------|
| Display | `--font-display` | 'Barlow Condensed', sans-serif |
| Body | `--font-body` | 'Inter', sans-serif |

### Type Scale

| Role | CSS Custom Property | Size (rem) | px equiv | Weight | Line Height | Font family | Usage |
|------|--------------------|-----------:|---------:|--------|-------------|-------------|-------|
| Body | `--text-body` | 1.6rem | 16px | 400 | 1.5 | `--font-body` | Paragraphs, descriptions, nav links |
| Label | `--text-label` | 1.4rem | 14px | 600 | 1.4 | `--font-body` | Captions, badges, metadata, button text |
| Heading | `--text-heading` | 2.4rem | 24px | 600 | 1.2 | `--font-body` | Card titles, section subheadings, section headers, navbar brand text |
| Display-lg | `--text-display-lg` | clamp(4rem, 6vw, 9rem) | 40–90px | 900 | 1.0 | `--font-display` | Hero title, stats numbers |

**Exception — 4 weights across 2 font families:** This system uses 4 weight values (Inter 400, Inter 600, Barlow Condensed 700, Barlow Condensed 900). This exceeds the 2-weight default rule but is justified by strict family-role segregation: Inter handles all body/UI text (2 weights within that family), Barlow Condensed handles all display text (2 weights within that family). No family uses more than 2 weights. The checker should treat each family's weight budget independently.

**Display font usage rules:**
- `text-transform: uppercase` on all Barlow Condensed instances
- `letter-spacing: 0.02em` on all Barlow Condensed instances
- Barlow Condensed 900 reserved for hero headline and large stat numbers only
- Barlow Condensed 700 reserved for display-lg non-hero contexts (future phases)

**Body font usage rules:**
- Weight 400 for body copy and nav links
- Weight 600 for labels, card titles, button text, headings
- No weight above 600 for Inter in this design system

**Important flag from STATE.md:** Amber accent (`#c8960c`) must be validated against the actual company logo (`public/sbLogo.png`) before Phase 1 is marked complete. If logo colors conflict, update `--color-accent` and `--color-accent-hover` before any Phase 2 work begins.

## WebP Image Convention

### Service Card Images

The 6 service category images live in `src/img/services/` as PNG files. These are imported directly into `ServicesPage.jsx` via ES module imports.

**Current PNG filenames → Target WOFF2 filenames:**

| # | Current (PNG, src/img/services/) | Target (WebP, public/img/services/) | Category |
|---|----------------------------------|--------------------------------------|----------|
| 1 | `elektrikliElAletleri.png` | `elektrikli-el-aletleri.webp` | Elektrikli El Aletleri |
| 2 | `isGuvenligi.png` | `is-guvenligi.webp` | Is Guvenligi |
| 3 | `nalburiye.png` | `nalburiye.webp` | Nalburiye |
| 4 | `tesisatMalzemeleri.png` | `tesisat-malzemeleri.webp` | Tesisat Malzemeleri |
| 5 | `yapiKimyasallari.png` | `yapi-kimyasallari.webp` | Yapi Kimyasallari |
| 6 | `yapiMalzemeleri.png` | `yapi-malzemeleri.webp` | Yapi Malzemeleri |

**Naming convention rules:**
- camelCase → kebab-case (matches URL-safe conventions)
- `.png` → `.webp`
- Move from `src/img/services/` (bundler-imported) to `public/img/services/` (served as static assets, referenced by path string)
- Target max file size: 100 KB per image (quality 82, method 6 recommended for cwebp)

**Reference pattern in ServicesPage.jsx (replaces ES import):**
```jsx
// Before (ES module import — forces bundler to copy PNG):
import elektrikliElAletleri from "../img/services/elektrikliElAletleri.png";

// After (public path string — served directly):
const img = "/img/services/elektrikli-el-aletleri.webp";
```

**Why move to `public/`:** WebP files served as static assets do not need to pass through the Vite bundler. Using public paths also enables future `<picture>` srcset patterns without import changes.

## :root Token Block Structure

The complete `:root` block must appear as the **first CSS rule** in `src/index.css`, above the existing `@font-face` declarations. Order within the block:

1. Color tokens (`--color-*`)
2. Font family tokens (`--font-*`)
3. Type scale tokens (`--text-*`)
4. Spacing tokens (`--space-*`)
5. Z-index tokens (`--z-*`)
6. Motion tokens (`--ease-*`, `--duration-*`)

Comment each group clearly. Include a note: `/* 1rem = 10px (html font-size: 62.5%) */` at the top of the block.
