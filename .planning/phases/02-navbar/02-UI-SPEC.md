## Spacing Scale

Source: `:root` token block in `src/index.css` (Phase 1). All values use `1rem = 10px` convention.

| Token | CSS Variable | Computed | Usage |
|-------|-------------|----------|-------|
| xs | `--space-xs` | 4px (0.4rem) | Icon gap within link item |
| sm | `--space-sm` | 8px (0.8rem) | Logo text left offset, tight gaps |
| md | `--space-md` | 16px (1.6rem) | Navbar horizontal padding (mobile) |
| lg | `--space-lg` | 24px (2.4rem) | Navbar horizontal padding (desktop), link gap |
| xl | `--space-xl` | 32px (3.2rem) | Max link group gap (desktop wide) |
| 2xl | `--space-2xl` | 48px (4.8rem) | Not used in navbar |
| 3xl | `--space-3xl` | 64px (6.4rem) | Not used in navbar |

Exceptions:
- Navbar height is a fixed dimension, not a spacing token: **56px mobile / 64px tablet / 72px desktop**.
- Touch target minimum for hamburger button: 44px × 44px (accessibility requirement, not an 8pt grid value).
- Logo divider line height: matches logo image height, not a spacing token.

| Role | CSS Variable | Size | Font | Weight | Letter-Spacing | Line Height |
|------|-------------|------|------|--------|---------------|-------------|
| Nav link (desktop) | `--text-subheading` | 2.0rem (20px) | `--font-display` (Barlow Condensed) | 700 | 0.08em | 1 (single line) |
| Nav link (tablet ≥640px) | `--text-body` | 1.6rem (16px) | `--font-display` (Barlow Condensed) | 700 | 0.08em | 1 |

| Logo wordmark (desktop ≥1024px) | `--text-heading` | 2.4rem (24px) | `--font-display` (Barlow Condensed) | 900 | 0.04em | 1 |
| Logo wordmark (tablet ≥640px) | `--text-body` | 1.6rem (16px) | `--font-display` (Barlow Condensed) | 900 | 0.04em | 1 |

Typography scale is exactly 4 sizes: **14px, 16px, 20px, 24px**.

Icons in nav links: Phosphor icons at 20px (mobile/tablet) and 22px (desktop). `aria-hidden="true"` on all decorative icon instances.

## Color

Source: Phase 1 `:root` token block. All values are CSS custom property references.

| Role | CSS Variable | Hex | Usage |
|------|-------------|-----|-------|
| Dominant (60%) — navbar bg | `--color-bg` | `#0f1923` | Navbar background (replaces old `#fefcfb81` semi-transparent) |
| Secondary (30%) — surface | `--color-surface` | `#1a2840` | Navbar bottom border, mobile drawer background |
| Accent (10%) | `--color-accent` | `#c8960c` | Active link indicator, hover text color, logo divider line |
| Accent hover | `--color-accent-hover` | `#e8b010` | Hover state on accent elements (logo divider on logo hover) |
| Text primary | `--color-text-primary` | `#f0ebe4` | Default link text, logo wordmark text |
| Text muted | `--color-text-muted` | `#7a8fa8` | Inactive/unfocused link text on desktop |
| Border | `--color-border` | `#253347` | Navbar bottom border (1px solid), logo divider |
| Destructive | `--color-destructive` | `#c0392b` | Not used in navbar |

**Accent reserved for:**
- Active (current route) link text color
- Active link indicator (2px bottom border or left border on mobile drawer)
- Logo area divider line color (`::after` pseudo-element)
- Hover text color on non-active nav links

Default (idle) link text: `--color-text-muted` (`#7a8fa8`) — not white. This creates contrast between idle and active/hover states.

**Old corporate blue (`#194d88`) must be fully removed.** All references to `#194d88` in `.navbar`, `.nav-logo-container`, `.navbar-links_link`, `.nav-logo-text` are replaced.

## Component Anatomy

### Desktop Navbar (≥640px)

```
┌─────────────────────────────────────────────────────────────────┐
│  [logo img]  SB TEKNİK MALZEME  │  Hakkımızda  Hizmetlerimiz  İletişim  │
└─────────────────────────────────────────────────────────────────┘
  ← logo area (flex row) →  vertical divider  ← links row (flex) →
```

- `position: sticky; top: 0` — navbar sticks to top on scroll
- `z-index: var(--z-navbar)` — 300, above all page content
- Full-width, `width: 100%`
- Background: `var(--color-bg)` with `backdrop-filter: blur(8px)` for depth when scrolled over content
- Bottom border: `1px solid var(--color-border)`
- Horizontal padding: `var(--space-lg)` (24px) left and right
- Height: 64px tablet, 72px desktop

### Mobile Navbar (<640px)

```
┌────────────────────────────────┐
│  [logo img]  SB TEKNİK  ☰      │   ← collapsed bar
└────────────────────────────────┘

 (when open)
┌────────────────────────────────┐
│  [logo img]  SB TEKNİK  ✕      │
├────────────────────────────────┤
│  Hakkımızda                    │
│  Hizmetlerimiz                 │
│  İletişim                      │
└────────────────────────────────┘
```

- Hamburger toggle button: 44×44px touch target, icon-only (Phosphor `List` / `X` icons at 24px)
- Drawer slides down from below the bar (not full-screen overlay) — `max-height` animation from 0 to content height
- Drawer background: `var(--color-surface)` (`#1a2840`)
- Drawer links: stacked vertically, `padding: var(--space-md) var(--space-lg)` each
- Active link in drawer: `--color-accent` left border (3px) + `--color-accent` text

### Logo Area

- Logo image: `sbLogo.png` (existing asset) — height 56px mobile, 64px tablet, 72px desktop
- Logo wordmark: "SB TEKNİK MALZEME" — uppercase via `text-transform: uppercase`, Barlow Condensed 900
- Vertical divider between logo image and wordmark: `::after` pseudo-element, `1px solid var(--color-accent)`, height 40px (centered)
- The existing `nav-logo-container::after` border uses `#194d88` — replace with `var(--color-accent)`
- Logo group is a `<Link to="/">` with `aria-label="Ana Sayfa"`

## Hover and Active States

### Link hover (desktop/tablet, non-active link)

- Text color: `var(--color-text-muted)` → `var(--color-accent)` (`#c8960c`)
- Icon color: follows text color (inherits via `currentColor`)
- Transition: `color var(--duration-fast) var(--ease-out)` (150ms)
- No underline. No background change. Color-only transition.

### Active link (current route, all viewports)

Detected via React Router `NavLink` with `className` callback or `useMatch`:
- Text color: `var(--color-accent)` (static, not transitioning)
- Icon color: `var(--color-accent)` (via `currentColor`)
- Desktop: 2px bottom border `var(--color-accent)` on the link element
- Mobile drawer: 3px left border `var(--color-accent)` + text color `var(--color-accent)`
- Font weight: 700 (same as idle — no weight change needed given Barlow Condensed already reads as strong)

### Logo hover

- Wordmark text: `var(--color-text-primary)` → `var(--color-accent-hover)` (`#e8b010`)
- Divider line: `var(--color-accent)` → `var(--color-accent-hover)`
- Transition: `color var(--duration-fast) var(--ease-out)`

### Hamburger button hover/focus

- Background: `transparent` → `rgba(200, 150, 12, 0.12)` (accent at 12% opacity)
- Border-radius: 4px
- Transition: `background-color var(--duration-fast) var(--ease-out)`

## Scroll Behavior

`position: sticky; top: 0` — navbar stays at top of viewport as user scrolls.

No scroll-triggered visual change (no color shift on scroll, no shadow reveal). The `backdrop-filter: blur(8px)` provides sufficient depth separation from page content in all scroll states.

The existing codebase has no scroll-detection logic — do not add it. Sticky CSS is sufficient and zero-JS.

## Animation

Motion library (`motion/react` v12) available. Use sparingly — industrial aesthetic favors restraint over flourish.

| Element | Animation | Spec |
|---------|-----------|------|
| Mobile drawer open | `motion.div` height reveal | `initial: { height: 0, opacity: 0 }` → `animate: { height: "auto", opacity: 1 }` — spring `{ type: "spring", stiffness: 300, damping: 30 }` |
| Mobile drawer close | Same variant reversed | `exit: { height: 0, opacity: 0 }` — duration 150ms |
| Hamburger icon swap | `AnimatePresence` key swap | `List` ↔ `X` icon — fade in/out, `duration: 0.15s` |
| Nav link hover | CSS transition only | No motion/react needed — `color var(--duration-fast) var(--ease-out)` |
| Page entrance | None | Navbar has no entrance animation — it must be visible immediately |

`AnimatePresence` wraps the mobile drawer for clean mount/unmount.

`prefers-reduced-motion`: When `useReducedMotion()` returns true, skip drawer spring — use instant show/hide (`duration: 0`).

## Accessibility

| Requirement | Implementation |
|------------|---------------|
| Keyboard navigation | All links and hamburger button reachable via Tab in DOM order |
| Focus ring | `outline: 2px solid var(--color-accent); outline-offset: 3px` on `:focus-visible` — replaces any browser default |
| Hamburger button role | `<button>` element (not `<div>`) with `aria-label="Menüyü aç"` / `"Menüyü kapat"` toggled via state |
| Hamburger expanded state | `aria-expanded={isOpen}` on the button element |
| Mobile drawer | `aria-hidden={!isOpen}` on the drawer `<nav>` when collapsed |
| Logo link | `aria-label="Ana Sayfa"` on the `<Link>` wrapping logo image + wordmark |
| Decorative icons | `aria-hidden="true"` on all Phosphor icon instances inside nav links |
| Active link | `aria-current="page"` on the active `<NavLink>` (React Router NavLink handles this natively) |
| Skip link | Not required for this phase — navbar is the first focusable element and is compact |
| Color contrast | `--color-accent` (#c8960c) on `--color-bg` (#0f1923): contrast ratio ~5.2:1 — passes WCAG AA for large text (Barlow Condensed 700 at 20px qualifies). `--color-text-primary` (#f0ebe4) on `--color-bg`: ~14:1 — passes AAA |
